- Python >= 3.10
- pip
- Visual Studio Code (opcional)
- Git

---

# 🚀 Instalación

## 🔹 Clonar el repositorio

```bash
git clone https://github.com/JP-hub-coder/Proyecto_PythonJuanBeltran.git
```

Entrar al proyecto:

```bash
cd Proyecto_PythonJuanBeltran
```

---

# ▶️ Ejecutar Proyecto

Ejecutar archivo Python:

```bash
python main.py
```

o

```bash
python3 main.py
```

---

# 📦 Instalar Dependencias

Si el proyecto incluye `requirements.txt`:

```bash
pip install -r requirements.txt
```
